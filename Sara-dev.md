## Selected Work

A few things I have built on my way to becoming a developer. Each one started as an idea and ended as a lesson.

### GreenOasis
**Storefront UI | 2025**

A front-end storefront for an imaginary plant shop, built from scratch to practice responsive layout, modern UI patterns, and interactive components.

I built the entire storefront with nothing but HTML, CSS, and JavaScript, no frameworks, no build step and no dependencies. The goal was to sharpen the fundamentals: a responsive grid that holds up on every screen, a clean product browsing experience, and small interactive touches that make the page feel alive rather than static.

- **Live Demo:** [saraebrahem194-del.github.io/Green-oasis](https://saraebrahem194-del.github.io/Green-oasis/)
- **Tags:** HTML, CSS, JavaScript

### TaskFlow
**Full-stack task dashboard | 2026**

A lightweight task command center for managing daily work, with live filters, search, and a local database that keeps every change saved.

I turned a basic to-do list into a full-stack dashboard where every action, adding, editing, deleting, and filtering, happens without a page reload or a single frontend framework. The interface was designed around the rhythm of daily task management rather than generic admin patterns, with clear states and keyboard-friendly flows.

- **Tags:** Vanilla JS, Express, Node.js
